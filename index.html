----------------------------------------
Keybinds
----------------------------------------

Space           Play / Stop
Shift+Space     Play from mouse position
[ ]             Move playhead

Z               Undo
Y / Shift+Z     Redo
C X V           Copy / Cut / Paste

0–9             Set pattern number
Arrow Keys      Move selection (Shift extends)
Ctrl+Up/Down    Move channel

Enter           Add bar after
Shift+Enter     Add bar before
Backspace       Delete bar
Ctrl+Enter      Add channel
Ctrl+Backspace  Delete channel

D               Duplicate pattern
N               New pattern
+ -             Move notes (Shift for octaves)

A               Select song
Shift+A         Select channel
F / H           Go to first / highlighted bar
Shift+F         Set loop start
B               Loop bar
Alt+B           Set loop to selection

S               Solo
M               Mute
Shift+M         Mute all

R               Random preset
Shift+R         Random instrument
Alt+R           Selective random instrument
Alt+V           Selective paste instrument

Shift+P         Song player
Alt+E / Alt+F   Open / close envelope or FM sections
Shift+~         New song
Q               Channel settings
